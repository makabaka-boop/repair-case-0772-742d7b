# 电梯与楼层导向铭牌 · 触觉版压点前预检

纯浏览器单页应用（Vue 3 + TypeScript + Vite）。制版员键入短句并选择每行方数（4–20），
页面按仓库内固定编码表逐方预览六点点位、数字符位置、换行与总方数，压点前直接发现差错。

**不请求任何在线转换接口**：编码、排版全部在浏览器本地完成。

## 编码规则（固定表，见 `src/lib/braille.ts`）

六点编号，左列 1、2、3，右列 4、5、6：

```
1 ─ 4
2 ─ 5
3 ─ 6
```

| 字符 | 点号方 |
| --- | --- |
| 一 二 三 四 五 六 七 八 九 零 | `1` `12` `14` `145` `15` `124` `1245` `125` `24` `245` |
| 半角 0–9 | 沿用对应中文数字编码（0→零`245`，1→一`1`，…，9→九`24`） |
| 数字符（每段连续半角数字前自动插入一方） | `3456` |
| 逗号 `，` / 句号 `。` / 连字符 `-` / 空格 | `2` / `256` / `36` / 空方 |

- 半角数字串遇到**任何非数字字符**即结束；下一段数字前重新插入数字符 `3456`。
- 中文数字不触发数字符。
- 允许字符仅限：`一二三四五六七八九零`、半角 `0-9`、空格、`，。-`。
- 排版：逐方填充，达到行宽换行，**不拆分编码方，也不补齐末行**。
- **非法字符、空文本或非法行宽（非 4–20 的整数）阻止全部输出。**

## 双稿核对

压点车间常收到内容相近的“审核稿”和“制版稿”，只看字面容易漏掉数字段变化
引起的数字符位移。页面顶部可切换到**双稿核对**模式：分别粘贴两份短句并点击
“发起核对”，页面复用同一固定编码器把两稿转成**带来源索引**的方序列，再由
比对服务做一套确定性的最短编辑对齐，逐项标出首个差异及后续插入、删除、替换，
并注明每方来自原稿第几个字；空方与数字符照常可辨认。

- 两稿完全一致时给出明确结论（总方数、无差异）。
- 任一稿为空或含非法字符时，**只在对应输入旁反馈出错位置并停止比对**，不产生差异表。
- 核对对象是一次双稿差异记录，不做行宽排版；单稿预检的输入、排版、总方数与错误阻断行为不受影响。

## 试压校准

换模或保养后，班组先压一张**六点试压片**，避免设备偏压影响随后生产的铭牌。
页面顶部可切换到独立的**试压校准**工作区：操作员为 1 至 6 号点分别录入一次
凸点高度（毫米）并点击“执行判定”，页面按点展示实测值、越界原因与整机结论。

- 单点合格范围固定为 **0.60–0.90 毫米**（含边界）；六点最大值与最小值之差（极差）
  **不超过 0.15 毫米**（含边界）。
- 空值（缺项）、非数字、非有限数、**超过两位小数**或**非正数**都在对应点位就地提示，
  并**停止判定**（不产生任何阈值结论）。
- 读数全部有效但阈值不满足时，正常生成 **“需调机”** 结果并逐项列出越界原因，
  与输入错误严格区分；阈值全过则为 **“合格”**，可以投入铭牌压点生产。
- 未提交草稿自动保存在浏览器 localStorage，刷新后重新进入工作区即恢复；
  一次成功判定（合格或需调机）的本次结果在刷新后保留，任一读数再被修改后上次结论立即失效。
- 校准会话是完全独立的工作区：**不读取也不改写**单稿预检与双稿核对的任何输入或结果，
  全部计算仍在本机完成，离线可用。

## 识读训练

新上岗制版员独立操作前需完成点位识读练习。页面顶部可切换到独立的**识读训练**工作区：
点击“开始训练”后，依次查看由既有固定编码表生成的**十张盲文方卡片**，每题从四个字符
选项中作答，提交后立即显示正确字符与点号说明（第几点凸起），局末汇总答对数与错题。

- 题目由领域层按**可注入种子**生成：同一种子得到完全相同的题序与选项顺序；
  一局十题互不重复，每题四个选项且恰好一个正确字符。
- 训练服务维护当前题号、作答记录与成绩契约：**每题只允许提交一次**，
  局次完成前**阻止重复开局**；题目生成异常时页面给出**无法开局**反馈，不出现空白题卡。
- 局次**不做本地保存**：刷新页面或离开本工作区即直接结束未完成局次。
- 识读训练是完全独立的工作区：**不读取也不改写**单稿预检、双稿核对与试压校准的
  任何数据，全部计算仍在本机完成，离线可用。

## 本地开发

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # 类型检查 + 输出单页应用到 dist/
npm run preview    # 预览构建产物 http://localhost:4173
```

## 验收测试

```bash
npm run test:unit  # Vitest：编码表、数字符边界、行宽边界、逐方排版、双稿对齐与来源索引、试压校准边界/离散度/无效读数与草稿持久化、识读训练种子确定性/十题不重复/计分与提交约束
npx playwright install --with-deps chromium   # 首次运行 E2E 需要
npm run test:e2e   # Playwright：错误字符阻止输出、制版点位、换行、双稿核对主流程、试压校准主流程与刷新恢复、识读训练开局/连续作答至成绩页/重复提交拦截与模式隔离、无在线请求
npm test           # 单元测试 + E2E
```

## Docker Compose

默认只运行 `web`（nginx 托管静态文件）：

```bash
docker compose up web                 # 宿主端口默认 8080
WEB_PORT=9090 docker compose up -d web
```

一次性验收服务（Vitest + 构建 + Playwright，运行结束即退出）：

```bash
docker compose run --rm verify
```

## 目录

```
src/lib/braille.ts    固定编码表与逐字编码（纯函数，含带来源索引的编码契约）
src/lib/layout.ts     行宽校验与逐方换行
src/lib/precheck.ts   单稿预检总入口（任一非法即阻止全部输出）
src/lib/compare.ts    双稿核对（确定性的最短编辑对齐，输出相同/存在差异/输入受阻）
src/lib/calibration.ts      试压校准领域服务（十进制解析、缺项检查、阈值计算与判定契约）
src/lib/calibrationStorage.ts 校准草稿与本次成功判定的 localStorage 持久化（领域服务不接触存储）
src/lib/training.ts       识读训练领域服务（可注入种子的题目生成、当前题号/作答记录/成绩契约）
src/components/CellView.vue  单方可复用渲染（六点网格 + 点号标签，空方与数字符可辨认）
src/components/CalibrationWorkspace.vue  试压校准工作区（只消费校准契约，独立于既有两种模式）
src/components/TrainingWorkspace.vue  识读训练工作区（复用 CellView 渲染题卡，局次不做本地保存）
src/App.vue           模式切换、单稿输入与逐方预览、双稿差异记录
tests/unit            Vitest
tests/e2e             Playwright
```
